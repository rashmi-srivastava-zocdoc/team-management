Jira Board Confluence PagerDuty GitHub Team #provider-peacock-team #provider-peacock-prs Email

Team Mission

We enable healthcare providers to join Zocdoc quickly and easily, ensuring they can start seeing patients as soon as possible. Our focus is on reducing friction in the onboarding process while maintaining data quality and compliance.

Key Objectives

  • Reduce time-to-activation for new providers
  • Increase self-service onboarding completion rates
  • Improve provider data quality through better validation
  • Scale onboarding infrastructure for enterprise customers

A C# service for hosting client-side rendered (CSR) web applications outside the monolith.

Purpose

A thin layer that serves client-side web apps without going through the monolith.

How It Works

Fetches pre-built HTML from Velocity Raptor (the asset deployment system) and serves it to users. When you have a React/frontend app that doesn't need server-side rendering from the monolith, you add a controller here that serves the HTML shell, and the client-side JS takes over from there.

Future Enhancements
  • Bootstrapping data into HTML (porting logic from the monolith's BootstrapDataHtmlService)
  • Decoupling from monolith's velocity raptor canary deploy
